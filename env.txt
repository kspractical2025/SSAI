Press the Windows Key, type Registry Editor, and run it as Administrator.

Navigate to: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\FileSystem

Find the key named LongPathsEnabled.

Double-click it and change the Value data from 0 to 1.

Restart your computer for this change to take effect.
